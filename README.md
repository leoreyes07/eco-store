## 📖 Overview

**Eco-Store** is a static, highly responsive front-end project designed to showcase an eco-friendly online store interface. 
It serves as a strong foundation for building sustainable-themed e-commerce platforms, landing pages, or simply as a clean template for front-end practice. 

Built with the principles of **modular design** using SASS, it emphasizes a clean architecture, separation of concerns, and reusable styling components.

## ✨ Features

- 📱 **Fully Responsive Layout:** Optimized for mobile, tablet, and desktop devices.
- 🎨 **SASS/SCSS Architecture:** Modular, scalable, and maintainable CSS structure.
- ♻️ **Eco-Themed UI:** Clean, minimalist, and nature-inspired aesthetic.
- ⚡ **Lightweight & Fast:** Zero heavy JavaScript dependencies, pure structural HTML5 and CSS.
- 🧩 **Reusable Components:** Designed with UI atomic components for easy scalability.

## 🛠️ Tech Stack

- **HTML5:** Semantic structure and layout.
- **SASS (SCSS):** Advanced CSS preprocessor for variables, nesting, and mixins.
- **CSS3:** Compiled styles and responsive media queries.

## 🚀 Getting Started

Since this is a static web project, getting started is incredibly simple. No complex bundlers or servers are required to view the UI.

### Prerequisites

If you plan to modify the styles, you will need a SASS compiler. We recommend using the [Live Sass Compiler](https://marketplace.visualstudio.com/items?itemName=ritwickdey.live-sass) extension for VS Code or running SASS via CLI.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/leoreyes07/eco-store.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd eco-store
   ```
3. **Open the project:**
   Simply double-click the `index.html` file, or open it in your browser, or use VS Code's Live Server extension for hot reloading.

## 🎯 Why SASS?

This project uses SASS to demonstrate clean styling architecture. By using variables, mixins, and nested rules, the codebase remains DRY (Don't Repeat Yourself) and makes global theme changes (like modifying the primary eco-green color) a one-line task.
